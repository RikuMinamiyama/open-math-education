## スキーマ

TeXファイルの先頭にコメントアウトされた**YAML Front Matter**形式で記述する。
4行目から次の空行の手前までを対象とする。

% Metadata
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% id: jmo-2026-y-1
% title: 2026年 第36回 日本数学オリンピック 予選問題 第1問

% difficulty: 1
% source: https://www.imojp.org/archive/mo2026/jmo/problems/jmo36yqa.pdf
