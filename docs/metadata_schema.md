# メタデータ

## スキーマ

TeXファイルの先頭にコメントアウトされた**YAML Front Matter**形式で記述する。
4行目から次の空行の手前までを対象とする。

```tex
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% Metadata
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% id: jmo-2026-y-1
% title: 2026年 第36回 日本数学オリンピック 予選問題 第1問
% tags: [整数]
% difficulty: 1
% source: https://www.imojp.org/archive/mo2026/jmo/problems/jmo36yqa.pdf
```

## IDの命名規則

ファイルのパス（`src/contents` 以下）をハイフンで結合する．

`src/contents/jmo/2026/y/1.tex` → `jmo-2026-y-1`

## タイトル

| 種類 | タイトル |
| :-- | :-- |
| 典型問題 | 内容が分かる程度に具体的に書いて良い |
| 自作問題 | 自由に決めて良い |
| イベント問題 | どのイベントのどの問題か特定できる情報をまとめる |

## 難易度の算定基準

以下の基準を目安に皆さんん感覚でつけてください．難易度に意義がある場合はissueを立てて議論しましょう！

| 評価 | 基準 |
| :-- | :-- |
| ★ | 一般的な教科書の例題レベル |
| ★★ | 教科書の練習問題レベル |
| ★★★ | 定期試験・共通テスト基本問題レベル |
| ★★★★ | 共通テスト応用問題・地方国公立大学入試レベル |
| ★★★★★ | 中堅国公立大学・難関私立大学入試レベル |
| ★★★★★★ | 難関国公立大学・最難関私立大学入試レベル |
| ★★★★★★★ | 大学入試最難関レベル |
| ★★★★★★★★ | 数学オリンピック予選レベル |
| ★★★★★★★★★ | 数学オリンピック本選レベル |
| ★★★★★★★★★★ | IMO（国際数学オリンピック）レベル |

※ もちろん，数学オリンピック予選の問題でも，場合によっては★3程度になる可能性もあります．

## ソース

- 典型問題である場合は `general` とする．
- 典型問題でない自作問題は `original` とする．
- リンクがある場合はそのURLを記載する．
- リンクがない場合は引用元が特定できる情報を記載する．（例：2026年東大入試理系第1問）
