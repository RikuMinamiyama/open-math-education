# やさしいみんなの数学

誰もが良質な数学教材に平等にアクセスできる環境を目指す、AI添削を核にした数学の演習アプリです。

- 単元・項目ごとの問題演習
- 手書き答案を撮影してアップロードするとAIが添削
- 問題・解説は [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja) で公開
